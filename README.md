# HydroSeal Gel — No-Install Advanced AI Simulation

This is a static website project built with HTML, CSS, and browser JavaScript. You do **not** need Node.js, npm, Python, VS Code extensions, or any other installation to use the visual simulation.

## Start the website

1. Extract the ZIP file.
2. Open the `AKBV` folder.
3. Double-click `index.html`. It should open in your default browser.
4. Scroll to **HydroSeal AI Waterproofing Simulator**.
5. Adjust water exposure, crack severity, application coverage, surface material, and observed condition.
6. Click **Run scenario analysis** for a detailed offline explanation, or **Compare treated vs untreated** to compare the illustrative rule-based scores.

## Optional live Gemini AI (no installation)

The local simulation works without internet and without an API key. To request a real Gemini-generated explanation instead:

1. Create a fresh key at https://aistudio.google.com/app/apikey.
2. In the simulator's **Optional Gemini API key** field, paste the key.
3. Click **Run scenario analysis**. The page sends the scenario to Google's Gemini API from your browser.
4. The key is kept in page memory only and is not saved to local storage. Reloading the page clears the field.

**Security warning:** This direct-browser option is intended only for a private classroom/demo session. The key can be inspected by the browser and may be exposed to anyone with access to your session or developer tools. Do not embed a key in source code or use this method on a public website. For public deployment, use a hosted serverless/backend proxy with a secret environment variable; that requires deployment setup but not a local Node.js installation. Never reuse a key that has already been shared publicly.

Live Gemini access requires an internet connection, a valid key, API/model access, and available quota. Google may change free-tier models, quotas, and regional eligibility. If the live API request fails or browser access is blocked, the local simulation still works.

## What the simulation means

The concrete wall animation, treatment effects, risk index, and comparisons are educational visualizations generated by simple JavaScript rules. They are not real fluid-dynamics calculations, measured leakage probabilities, laboratory results, or proof of HydroSeal Gel performance. Gemini provides explanatory text only; it does not validate the product. Confirm the real formulation and claims against verified manufacturer documentation and physical testing. Active seepage, persistent leaks, structural movement, or wide/growing cracks require qualified on-site assessment.
